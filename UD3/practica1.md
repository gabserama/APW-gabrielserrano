## 2. Pràctica: títol
Fer la tabla de la comparativa de Nextcloud,ownCloud i file run.

| Criteri | Nextcloud | ownCloud | FileRun |
|---|---|---|---|
| Llicència i model | Programari de codi obert (AGPLv3). Autohostat. | Programari de codi obert. Versió Community gratuïta i versions empresarials de pagament. | Programari propietari amb llicència comercial. |
| Tecnologia (llenguatge, base de dades) | PHP. MariaDB, MySQL, PostgreSQL i SQLite. | PHP (Classic) i Go (Infinite Scale). MySQL, MariaDB, PostgreSQL o SQLite (Classic). | PHP. MySQL o MariaDB. |
| Funcionalitats destacades | Sincronització d'arxius, compartició de documents, calendari, contactes, edició col·laborativa i videotelefonades mitjançant aplicacions. | Sincronització d'arxius, compartició, WebDAV, gestió d'usuaris i control de permisos. | Gestió i compartició d'arxius, vista prèvia de documents, enllaços públics i privats i cerca d'arxius. |
| Instal·lació amb Docker | Sí, disposa d'imatges oficials i Docker Compose. | Sí, disposa d'imatges oficials i Docker Compose. | Sí, disposa d'una imatge Docker. |
| Preu o limitacions de la versió lliure | Gratuït, sense límit d'usuaris per llicència. Les despeses depenen del servidor i del manteniment. | Community Edition gratuïta. El suport i les funcionalitats empresarials són de pagament. | No disposa d'una versió comunitària de codi obert. Les llicències són de pagament. |
| Font consultada | https://docs.nextcloud.com/server/stable/ | https://doc.owncloud.com/ | https://docs.filerun.com/ |
